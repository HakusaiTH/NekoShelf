## 🛠️ How to Run the Project Locally

1. Install Dependencies (first time only):
   ```bash
   npm install
   ```
2. Start the Server:
   ```bash
   npm start
   ```
3. Open your browser at: [http://localhost:3000](http://localhost:3000)
